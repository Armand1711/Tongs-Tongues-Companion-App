About This Project

A companion app for the Tongs & Tongues braai campaign.

What it does

  • Scan QR codes on physical coasters to collect braai phrases in Zulu, Xhosa and Afrikaans
  • Finish a language set to unlock a reward
  • Enter a monthly braai challenge, vote on entries and comment on them
  • The top entry wins a voucher and a place in the Hall of Fame

About this demo

No account needed. The people, entries, stores and voucher codes are sample content, and vouchers can't be redeemed.

Anything you do, including photos you add, stays in this browser and is never uploaded.

Built with

Next.js, React, TypeScript and Tailwind CSS. The full version used Supabase for accounts, the database and photo storage. This demo runs as a static site on GitHub Pages.
